# Prayer Times | مواقيت الصلاة

An Arabic (RTL) web app that shows the daily prayer times for Palestinian cities, using live data from the [Aladhan API](https://aladhan.com/prayer-times-api).


## Features

- Displays the six daily times: Fajr, Sunrise, Dhuhr, Asr, Maghrib, and Isha
- City selector (Hebron, Jerusalem, Bethlehem) that updates the times instantly
- Shows the current date with the Arabic weekday
- Fetches live data from a REST API using Axios
- Full right-to-left (RTL) Arabic interface

## Built With

- HTML5
- CSS3
- JavaScript
- Axios
- Aladhan Prayer Times API

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/AlaaObaid2004/prayer-Time.git
   ```
2. Open `index.html` in your browser (an internet connection is required to load the prayer times).

## What I Learned

- Sending HTTP requests and handling responses with Axios
- Working with a public REST API and reading JSON data
- Updating the DOM dynamically with JavaScript
